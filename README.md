# قطفة | Qatfah

هذا المستودع يحتوي على نموذج أولي قابل للبناء لأندرويد بواجهتي العميل والإدارة. تشمل نسخة العميل سجلات محلية للمبيعات والمشتريات والمصروفات والسندات مع تخزين محلي وعرض دون إنترنت. لا تستخدم هذه النسخة لبيانات مالية فعلية حتى إضافة خادم محمي ومراجعة المحاسبة والمزامنة والنسخ الاحتياطي. الإصدار الكامل قيد التطوير.
