# قطفة V2 — محاسبة محلية لأندرويد وويب

**الإصدار تجريبي للاختبار، وليس منتجًا معتمدًا ماليًا أو وسيلة إرسال واتساب آلية.**

## الوظائف الموجودة

- قوائم واجهات عربية بأيقونات ملونة، ساعة وحالة الدفتر، عميل وإدارة بتطبيقين منفصلين.
- فواتير البيع والشراء، عملاء وموردون وأصناف، «له / عليه»، سندات، تقارير يومية وشهرية وسنوية، عملات `YER` و`USD` و`SAR` منفصلة.
- إنشاء مستندات PDF محليًا مع شعار المحل، ومشاركة ملف PDF عبر Android Sharesheet؛ يختار المستخدم **واتساب** والمحادثة ثم يؤكد الإرسال. لا يمكن للتطبيق ضمان الإرسال تلقائيًا أو إرفاق الملف بمحادثة بعينها دون موافقة WhatsApp.
- شاشة WhatsApp Web مستقلة داخل Android WebView بوضع سطح المكتب، Cookies وDOM Storage. **قد تمنع واتساب عرض أو ربط WhatsApp Web داخل WebView**؛ وفي هذه الحالة يلزم استخدام واتساب أو المتصفح. رمز QR/Pairing Code يعرضه الموقع نفسه إن كان مدعومًا، ولا يولده قطفة.
- نسخ احتياطي محلي عبر `ACTION_CREATE_DOCUMENT` باسم `Qatfah_Backup_YYYY-MM-DD.json`، أو اختيار Google Drive المثبت كوجهة حفظ. الاستعادة عبر `ACTION_OPEN_DOCUMENT` بما فيه حساب Drive المثبت. لا يحتاج ذلك Google OAuth أو Cloud Project أو خادم. **النسخة JSON غير مشفرة** فتحتوي الأسماء والأرقام والحركات والشعار؛ احفظها بمكان آمن. Google Drive هنا خيار حفظ يدوي وليس مزامنة خلفية.
- العمل دون إنترنت بعد تسجيل الدخول إلى اشتراك فعال. عند أول تسجيل دخول يحتاج التطبيق اتصالًا لقراءة سجل الاشتراكات العام في GitHub، وبعدها يعمل سبعة أيام من آخر تحقق. الإيقاف لا يسري فورًا عند فصل الإنترنت.

## إدارة الاشتراكات المجانية على GitHub

- تطبيق المدير يُنشئ محليًا اسم مستخدم وكلمة مرور خاصة بالمدير (12 حرفًا فأكثر). يحفظ محليًا مُشتق PBKDF2 فقط، ويُشفّر تفويض GitHub وملاحظات المدير الخاصة بواسطة AES-GCM.
- **لإنشاء حسابات في GitHub يلزم مرة واحدة تفويض GitHub بصلاحية Contents: Read & Write على `i4i2009031-droid/nizami`.** GitHub لا يدعم تعديل المستودع باسم مستخدم وكلمة مرور فقط. التفويض يخص المدير ولا يوضع في APK أو المستودع.
- الاشتراكات تُسجَّل في `users.json` دون أرقام الهواتف أو كلمات المرور الخام؛ كلمات مرور العملاء تُولّد عشوائيًا بقوة 28 رمزًا وتُحفظ بصيغة تحقق PBKDF2 salted public. أسماء المحلات وأرقام الهواتف تُحفظ مشفرة على جهاز المدير فقط. **لا تستخدم كلمات مرور ضعيفة** لأن ملف الاشتراكات العام قابل للقراءة.
- لا تغيّر المستودع إلى Private إذا كان العملاء يقرؤون `users.json` بهذه الآلية؛ قراءة GitHub الخاص تتطلب تفويضًا لكل عميل أو خدمة تحقق مستقلة. لا يوجد نظام اشتراكات قوي آمن مع إيقاف فوري يعمل دائمًا دون إنترنت وخادم.

## البناء والاختبارات

تُعاد صور الهوية من `assets/encoded` ثم يعمل `scripts/build-web.mjs`. في Android تنفذ GitHub Actions `scripts/inject-android.mjs client` بعد إنشاء مشروع Capacitor، فتُدرج `QatfahNativePlugin.java` و`WhatsAppWebActivity.java` وتظهر أزرار حفظ/استعادة الملفات وواتساب ويب. يُبنى `qatfah-client.apk` و`qatfah-admin.apk` بصيغة Debug للاختبار فقط.

تشغيل `npm test` يفحص قواعد الحسابات والنسخ المحلية والتراخيص؛ نجاحه **لا يؤكد سلوك واتساب ويب على جهاز فعلي أو اعتماد الأرقام والإصدارات للإنتاج**. لا يوجد إرسال بدون اتصال بالشبكة وخدمة واتساب، ولا مزامنة تلقائية بين هاتفين.


## إضافات هندسة النظام المرجعي (تجريبية)

توجد الآن شاشة «الصرافة والحوالات» بنفس واجهة قطفة، مع تتبع الصندوق والبنك في YER وSAR وUSD، وسجلات مرجعية للحوالات والقيود المزدوجة واتزان كل عملة. تفاصيل تحليل الملف المرجعي وحدود النتائج موجودة في `docs/REFERENCE_ANALYSIS.md`.

شاشة واتساب المدمجة لم تعد تعرض الصفحة الكاملة؛ تحتوي على حالة الاتصال ومحاولة استخراج QR أو رمز الربط فقط. التوافق مع WhatsApp Web غير مضمون، ولا يوجد إرسال PDF خفي آلي؛ الإرسال عبر مشاركة أندرويد ويتطلب موافقة صاحب الهاتف.

## إرسال واتساب مباشر عبر خادم قطفة (تجريبي)

أضيفت شاشة اتصال بالخادم الآمن ضمن التطبيق وإرسال نصوص ومستندات PDF عبر `/api/whatsapp/send` و`/api/whatsapp/send-document` دون Android Sharesheet. يلزم ضبط `QATFAH_API_BASE` أو إدخال HTTPS وتسجيل حساب العميل على الخادم؛ وهو **مستقل** عن تسجيل دخول اشتراك GitHub. لتفعيل بوابة Baileys غير الرسمية يلزم `QATFAH_WHATSAPP_ENABLED=true` على الخادم وبيئة واتساب مرتبطة لكل عميل. توجد كذلك Cloud API رسمية اختيارية بإعداد مستقل. لا يعمل الإرسال عند عدم تفعيل الخدمة، ولا يُضمن وصول الرسالة بمجرد قبول طلب الإرسال. متصفح WebView الأصلي مخصص لتجربة الربط فقط، ولا تتم مزامنة جلسته مع جلسة الخادم. يجب تجربة APK الحقيقي قبل الإنتاج.
