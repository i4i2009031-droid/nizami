# قطفة: نسخة الويب (PWA)
تُبنى واجهة العميل من نفس المصدر الموجود في `apps/client`، وواجهة الإدارة من `apps/admin`، ضمن مهمة البناء الحالية.
- رابط GitHub Pages المتوقع بعد تفعيل النشر: https://i4i2009031-droid.github.io/nizami/
- الإدارة على المسار `/admin/`. يجب تقييد الوصول إلى أدوات الإدارة بأذونات مناسبة؛ الرابط وحده ليس حماية.
- يتم البناء بـ `npm run build:web` واستعادة الأيقونات أولاً عبر `node scripts/restore-assets.mjs`.
- في أندرويد يختار المستخدم جهة اتصال عبر منتقي النظام دون إذن قراءة جميع جهات الاتصال. في الويب نستخدم Contacts Picker API فقط حين يدعمه المتصفح وفي سياق HTTPS؛ وإلا يبقى الإدخال اليدوي متاحًا.
- الحسابات تستخدم سجل الاشتراكات نفسه؛ السجلات المالية تحفظ حالياً في IndexedDB محليًا لكل جهاز/متصفح، ولا توجد مزامنة مباشرة بين المتصفح وAPK. لنقل البيانات يدويًا يمكن تصدير واستيراد النسخة الاحتياطية.
- تظل جلسة واتساب المدمجة ميزة أندرويد أصلاً؛ نسخة المتصفح لا تدّعي القدرة على إرسال PDF صامتًا عبر محرك أندرويد.
- ينبغي التحقق من تمكين Pages في إعدادات المستودع ومن نجاح خطوة النشر في GitHub Actions قبل مشاركة الرابط مع العملاء.
